APK 夹具均为不可安装的合成文件。测试证明元数据解析的这些分支可用，不证明任意 APK 可安装、签名可信或 Android 设备兼容。

## 已知边界

- HTTP LAN 模式没有传输加密；可信设备共享一个私有工作区。
- 手机后台传输、下载管理器续传、系统保存位置均受浏览器/系统限制。
- V1 没有静默 APK 安装、ADB、PWA 安装、系统分享目标、后台剪贴板、自动目录监控或图片标注。
- 已完成文件不自动清理；搜索仅作用于已加载记录。
- 内置 APK 解析不验证签名、不解析资源引用；可选 SDK 只在内置结果不可用时回退。

不要把未执行的项目标为 PASS。环境限制应标为 BLOCKED，尚未开始的项目应标为 NOT RUN，并写明下一步。
