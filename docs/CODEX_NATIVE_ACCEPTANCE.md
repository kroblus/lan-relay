## Windows 应用验收

- 用隔离的测试数据目录构建并运行应用；不使用真实收件箱。
- 验证当前用户安装、桌面快捷方式、无须 Node/npm 的启动、浏览器自动打开管理页面。
- 再次双击只重新开页，不产生第二个服务；关闭网页后托盘服务继续工作。
- 托盘退出能优雅关闭对应 Node 进程；不能关闭其他项目的 Node 进程。
- 端口占用、中文/空格安装路径、启动失败和错误退出码有准确结果。
- 升级或卸载不删用户数据；旧源码版数据与新 App 数据不能悄悄混用。
- 如果旧服务还在运行，先确认后正常停止旧实例，不杀全体 Node 进程。

## Android App 验收

- 记录真实系统和 Android System WebView 版本，不预设我的手机仍是某个旧版本。
- 用试用包名测试；不要覆盖其他正式 App。稳定更新签名需要我本机保管的长期密钥，不把密钥上传 GitHub。
- 实测 App 内离线扫码、相机拒绝/允许、Android 17 局域网权限拒绝/允许、电脑批准、重新打开记住电脑。
- 验证默认设备名、预设和自定义；扫码自动带有效码，普通入口不使用固定默认码。
- 验证 WebView 自己的登录会话，不能依赖 Chrome 已登录。
- 手机原图、截图、录屏、APK 和中文多行文字双向传输；文件下载前后 SHA-256 一致。
- 系统文件选择多选、取消、返回重试；文件不可用时有明确提示。
- 下载及 Markdown 反馈导出真正出现在系统下载列表；认证失效不被当作 APK 下载成功。
- App 收到新的同页配对链接时能正确处理，不丢正在写的反馈或错误复用旧身份。
- 切后台、锁屏、中断、刷新后重选原文件恢复，按实际结果记录；不承诺系统不支持的后台持续传输。
- 窄屏和软键盘下主要按钮可见，320/375/430 px 与 150% 文字分开取证。
