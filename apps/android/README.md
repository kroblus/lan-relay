# Android 原生客户端 · 随手传 0.5.0

本模块是协议 2 的 Kotlin / Jetpack Compose 原生客户端，和 Rust 桌面配合使用。没有 WebView 内容页面或 JavaScript 原生桥。界面与 Rust 桌面统一为暖白、鼠尾草绿与少量淡紫/杏色点缀；底部导航为收发、传输、设备。首页用一个编辑区添加文字和文件，统一发送；项目标签、备用连接和开发者记录按需展开。

## 已实现的使用流程

1. 手机与电脑处于可互访的可信局域网，电脑运行 Rust 桌面应用。
2. 「设备」自动发现同一局域网的电脑，电脑也能发现前台打开的手机。选择电脑后无需输入连接码；核对两端显示的验证数字，在电脑点信任。电脑发起连接时，手机先显示确认提示。
3. 已信任电脑复用加密保存的会话，地址变化后先核对 server_id。首次验证不会授权局域网中的所有设备。二维码、手动地址与旧版连接码保留为备用入口；0.5 电脑手动地址连接也无需填写连接码。
4. 原生系统文件选择器支持原图、APK、录屏、普通文件与多选。选中的文件和系统分享进入统一草稿区，可以移除附件、附上文字后一次发送。选择文件时不会立即开始传输。
5. 文件按两端协商的分片发送，手机上限 8 MiB；旧服务或旧上传任务仍遵守其 2 MiB 等较小限制。原文件 SHA-256 增量计算；暂停/断网/进程重启后读取电脑已确认的 offset。任务始终绑定 server_id、device_id 和内容哈希。
6. 手机接收文件时使用可恢复的临时下载，完成 SHA-256 校验后通过 MediaStore 保存到 `下载/LANRelay`；原始字节不转码。APK 安装由用户通过系统明确操作，下载不能自动标记已安装或测试通过。
7. 最近内容会直接显示已保存文件的「查看图片」「安装应用」或「打开文件」按钮，无需回到传输列表。图片在应用内预览，普通文件遵循系统默认应用。首次 APK 安装引导开启系统安装权限，再打开系统安装界面；不会自动安装。
8. APK 的测试反馈和结果记录收进详情，是可选的开发者功能，不影响文件传输或安装。

## 0.5 体验与恢复更新

- 只对 `GET /api/v2/files/*` 取消整次请求的 120 秒总时限，保留 12 秒连接、45 秒读取空闲时限与主动取消。元数据和其他请求仍有总时限，健康的大文件流不会仅因累计两分钟而中断。
- 传输期间暂时断网、读取超时和 HTTP 408/429/502/503/504 最多自动恢复 3 次；从同步到磁盘的临时文件长度重新发 Range/If-Range，并重新核对电脑身份。证书、权限、文件身份、磁盘和 SHA 错误不自动重试。暂停与取消在退避等待中仍然有效。
- 下载响应必须提供与任务匹配的 SHA ETag，最终长度与 SHA 校验仍然保留。服务端返回完整 200 时先清空断点文件，绝不追加到旧内容。
- 文件打开按安全扩展名修正 MIME；APK 使用 `application/vnd.android.package-archive`、只读 content URI 授权与 ClipData。安装权限只在用户点击安装时请求；安装和验收状态不自动写为成功。
- 图片在 IO 线程解码为最长边不超过 2048 像素的预览，原图不转码、不覆盖。仅「用其他应用打开」主动显示选择器。
- 轻量反馈包括 140 毫秒附件/提示淡入、160 毫秒确认进度过渡和详情展开。没有持续装饰动画、全页模糊或高频背景动画。

### 局域网发现的边界

手机前台每 5 秒向 UDP 4319 广播一次，使用安装时生成的随机发现 ID 和设备名，不广播连接凭据。只处理私网 IPv4 的有限 JSON 报文；设备缓存 15 秒过期、最多 64 台，退后台关闭发现套接字。IP 来自报文发送地址，不接受广播里的任意 URL。发现结果仅提供连接提示，首次信任仍由桌面确认。访客 Wi-Fi、AP 隔离、广播禁用或防火墙可能阻止发现，此时使用备用地址连接。发现和数字比对不为 HTTP 增加加密或抵抗主动中间人攻击。

## 后台与恢复边界

- 本版采用用户在可见界面主动启动的 `dataSync` 前台服务，通知展示进度并支持暂停；没有开机自动启动、隐藏常驻或后台剪贴板监听。
- Android 15+ 的前台服务时间限制、系统停止、权限撤销和电量/资源策略仍适用。`onTimeout` 会停止服务并保留任务；进程意外退出后，活动任务恢复为暂停，用户点继续。
- 文档 URI 支持持久授权时保存权限；临时分享、授权失效、文件移动或删除后需要重选原文件，并重新验证大小和 SHA-256。不是所有 URI 都能永久恢复。
- 接收任务持有已保存的分片文件，原始下载长度和 SHA 必须匹配才能发布到公共下载目录。反馈 Markdown 导出有 4 MiB 上限，并依赖已认证的附件响应。
- 同一时间一个传输任务，防止并发缓冲和哈希拖慢手机。文件体不会整份转成内存数组或 base64。
- 页面不可见时不轮询内容列表。已经由用户启动的传输独立于页面运行；电脑新内容会在回到应用时刷新。
- 同 server_id 的电脑重新连接且原凭据仍有效时复用原 device_id。电脑撤销身份后重新配对会产生新身份，旧身份任务不会自动归属到新身份。
- 离线取消先停止本机任务，并保留电脑端取消待确认状态、任务 ID 与幂等请求 ID；连回原电脑后可重试。“清理完成记录”不会移除未确认的取消记录。

## 0.4 传输与界面更新

- 上传仍使用连续源流；每次恢复先向原电脑查询已持久化 offset，不信任 UI 缓存进度。源文件 SHA、上传 ID、幂等请求 ID、设备/电脑身份、阶段变化及暂停、取消、完成均立即写入原子任务日志。
- 只有可重建的进度缓存改为每 1 秒或 32 MiB 写一次（先到为准）；预哈希的文字进度只更新内存。通知最多每 500 毫秒刷新，阶段变化立即刷新。下载分片仍每 2 MiB 同步文件，完整性要求不变。
- 下载到公共目录时一边复制、一边计算 SHA-256，使用固定 256 KiB 缓冲；MediaStore 条目保持 IS_PENDING，长度和 SHA 全部匹配才发布。相比旧版先完整读一遍校验、再读一遍复制，最终保存阶段少读一遍完整文件。
- 传输卡区分准备/网络传输/校验保存，速度按实际收发字节的时间差计算，最多每 500 毫秒更新内存，排除预哈希和恢复定位；进度条与已确认字节仍只采用同步落盘或服务端确认的进度。4 秒无新网络字节时显示等待并隐藏旧 ETA；已完成不会混同为 APK 安装或测试通过。
- 这些是实现机制与测试观察，不代表任何 Wi-Fi 环境的保证速率。FEEM 的同设备同网络实测仍需独立执行；本机 HTTP 基准和 JVM 操作计数不能代替 Android 真机端到端结果。

## 网络与权限

- 允许私网 IPv4、IPv6 ULA/link-local、受控本地域名；本地域名解析结果必须仍是私网，拒绝公网、loopback、登录凭据 URL、任意文件路径入口。
- HTTP 是明确提示的局域网明文模式；HTTPS 使用系统正常证书验证，不接受忽略证书错误。
- API Bearer 凭据只发送给已批准 origin，HTTP 客户端不跟随重定向；凭据不放入 URL、日志、普通任务 JSON 或公共下载目录。
- 手动发送、翻页、反馈、测试状态与传输/取消都会先读取不带凭据的 hello，核对 server_id。切换电脑时先清空旧内容和反馈对话框，避免对新电脑操作旧内容。HTTP 下这只是身份一致性检查，不提供加密或抵抗主动冒充。
- Android 17 / target SDK 37 的 `ACCESS_LOCAL_NETWORK` 在开始发现或连接前请求；相机只用于主动扫码，先请求正常运行时权限，拒绝时说明原因，永久拒绝时引导打开应用设置；未授权不会启动扫码器。通知仅用于传输，`REQUEST_INSTALL_PACKAGES` 仅用于用户主动安装下载的 APK。不申请全盘存储、联系人或后台位置权限。
- 这是个人可信设备共享工作区，项目标签不是权限隔离。

## 构建

固定版本：JDK 17（必须包含 javac）、Gradle 9.4.1、AGP 9.2.1、内置 Kotlin / Compose compiler 2.2.10；Android SDK 37 与 build-tools 36.0.0。依赖版本固定在 Gradle 文件。

```sh
./apps/android/gradlew -p apps/android --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Windows 使用 `apps\android\gradlew.bat -p apps\android`，后接相同任务。也可以在 Android Studio 打开 `apps/android`。标准 Gradle Wrapper 由官方 Gradle 9.4.1 生成，发行包 SHA-256 已固定；首次需要下载经校验的发行包和固定依赖。CI 也可通过官方 setup-gradle 使用同一版本。

输出：

- 试用 APK：`app/build/outputs/apk/debug/app-debug.apk`
- JVM 报告：`app/build/reports/tests/testDebugUnitTest/index.html`
- Lint：`app/build/reports/lint-results-debug.html`
- 正式构建：`:app:assembleRelease`，默认未签名，不能直接安装。

本目录 `.gitignore` 排除 SDK、构建目录、local.properties、密钥和本地环境。不要把产物、凭据或测试用户文件提交 Git。

## 升级和旧版

版本号 `0.5.0` / `versionCode 5`。试用包继续使用 `com.kroblus.lanrelay.preview`，正式包使用 `com.kroblus.lanrelay`，两者是不同应用。CI 的 debug 密钥不是 Owner 的长期发布密钥，不同构建不保证覆盖安装；不要通过清除应用数据掩盖签名冲突。

覆盖更新需要相同 applicationId、兼容签名和合适的版本号。正式分发前由 Owner 保管长期签名密钥，私钥和密码不得进入仓库。

协议 2 不复用旧 WebView 的 Cookie、localStorage 队列或临时 URI 授权，也不会自动读取/清理旧数据。升级前保留旧应用和电脑数据，按项目迁移说明处理。新 APK 需要 Rust 协议 2 服务，旧 Node 服务不能直接代替。
